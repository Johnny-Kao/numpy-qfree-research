# NumPy Q-free Searchsorted Research

Independent, private, non-fork research repository for Q-free conservative selector experiments.

- Official upstream PR: https://github.com/numpy/numpy/pull/32895
- Original study: https://github.com/Johnny-Kao/numpy/tree/research/searchsorted-qfree-interval-screen
- CI runs are manual dispatch only, one small job, no scheduled or push-triggered builds.
- Existing NumPy fork and PR remain unchanged.

This repository initially contains only information-screen tests. Synthetic classification results must not be mistaken for native C++ performance sign-off.
